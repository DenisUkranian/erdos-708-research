# Erdős №708: точное значение g(8)=11

**Статус:** компьютерно-проверяемое доказательство, 24 ноября 2026 года. Все вычисления целочисленные; контрольный запуск завершился `ALL CHECKS PASS`. Результат пока не проходил внешнее рецензирование или формализацию нового случая в Lean.

## Результат

Для любых восьми различных целых чисел `A ⊆ {2,3,...}`, `M=max(A)`, и любого интервала `I={x+1,...,x+M}` (`x>=0`) существуют не более 11 различных чисел из `I`, произведение которых кратно `prod(A)`. Существует конкретный пример, которому необходимо именно 11 чисел. Таким образом, **g(8)=11** (конвенция «не более»).

## Зависимости

Верхняя граница использует установленные ранее `g(7)≤9`, `g(6)≤8`, `g(5)≤6`. Полный ранее подготовленный воспроизводимый пакет `g(7)=9`, включая `g(6)≤8`, вложен в `dependencies/ERDOS_708_g7_equals_9_proof_only.zip`. Результат `g(5)=6` заявлен с проверкой в Lean в работе John Tripodo, 19 November 2026: https://hexagonmath.org/pdf/2611.00694v1. Нижняя граница `g(8)≥11` не зависит от этих результатов.

## Запуск

Нужны Python 3.9+ и компилятор C++17 (`g++`). После распаковки архива в этой папке выполните:

```bash
python3 verify_all.py
```

Проверка заново:
- перечисляет все конечные исходные наборы после доказанных исключений;
- сравнивает полученные 57 515 векторов потребностей с архивом;
- заново генерирует и независимо проверяет 57 487 универсальных сертификатов по накопленным НОД;
- проверяет все 28 остаточных случаев по точной системе вычетов CRT (никаких случайных сдвигов);
- проверяет конкретный пример для нижней границы и вычисляет его оптимум целочисленным динамическим программированием;
- подтверждает аналитическую границу `M≥11538`.

Ожидаемая последняя строка:

```
ALL CHECKS PASS: upper g(8)<=11 conditional on g(7)<=9,g(6)<=8,g(5)<=6; lower g(8)>=11 unconditional
```

Для повторной проверки вложенного доказательства `g(7)=9` отдельно:

```bash
unzip dependencies/ERDOS_708_g7_equals_9_proof_only.zip -d /tmp/g7-proof
python3 /tmp/g7-proof/G7_EQUALS_9_PROOF/g7_exact/verify_all.py
```

## Структура архива

- `g8_exact_proof.pdf` — математический текст доказательства (английский).
- `g8_exact_proof.tex` — исходник PDF.
- `src/enumerate.cpp` — полный перебор оставшихся источников и векторов потребностей.
- `src/make_gcd_certificates.cpp` — генерация универсальных 11-слотовых сертификатов.
- `src/crt11.cpp` — точная проверка всех фаз 28 исключительных случаев.
- `src/lower8.cpp` — независимый 0/1-DP точного примера, требующего 11 чисел.
- `certificates/finite_demands.txt` — 57 515 различных векторов `(M,D2,D3,D5,D7)`.
- `certificates/slot_certificates.txt` — 57 487 явных сертификатов. Формат: `M D2 D3 D5 D7 11 h1 ... h11`.
- `certificates/crt_exceptions.txt` — 28 оставшихся потребностей, все проверены CRT.
- `verify_all.py` — проверяющий скрипт, *не доверяющий* сертификатам без повторной арифметической проверки.
- `dependencies/` — ранее полученное доказательство `g(7)=9`.

## Ключевое техническое замечание

Сертификат `h1,...,h11` действителен для **каждого** интервала длины `M`, если `hi≤M`, его произведение содержит необходимые степени простых и `gcd(h1...h(j−1),hj)≤floor(M/j)`. Это гарантирует последовательный выбор *различных* элементов интервала; повторное использование одной позиции не допускается. Оставшиеся CRT-сертификаты учитывают сдвиг по всем необходимым классам вычетов.
